# Media guide

The homepage uses a cinematic Bangladesh 4K travel film from YouTube as the hero/background and as two destination scene crops. The film covers multiple parts of Bangladesh, including Sylhet, Saint Martin's, Cox's Bazar and Bandarban. The embedded player is used instead of downloading and redistributing the creator's video.

The Bandarban waterfall scene uses the Wikimedia Commons **Damtua Waterfall Alikodom, Bandarban** video. It is 16:9, 1280×720 and licensed CC BY-SA 4.0. The site uses Wikimedia's Special:Redirect/file endpoint so the browser can stream it without bundling a 35 MB source file in the ZIP.

## Sources
